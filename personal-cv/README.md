## About This Project

This is a personal CV (Curriculum Vitae) website built as a university
project for IT415. It's a single-page site that introduces me, lists my
education and technical skills, and gives a way to get in touch. The goal
of the assignment was to create a first GitHub repository and get some
hands-on practice with HTML and CSS.

## Technologies Used

- **HTML5** — page structure and content
- **CSS3** — styling, layout, and responsive design
- **Google Fonts** — Lora (headings) and Inter (body text)

No frameworks or JavaScript libraries were used. The site is plain HTML
and CSS so it stays simple to read and explain.

## Project Structure

```
personal-cv/
├── index.html            # The CV page (content and structure)
├── style.css             # Styling for the CV page, shared by the portfolio
├── README.md             # This file
└── portfolio/
    ├── index.html        # The portfolio page (coursework & activities)
    └── portfolio.css     # Portfolio-specific styling; reuses style.css
└── images/
    └── logo.jpg
```

The portfolio recreates the content of my original Google Sites portfolio
as a page inside this same project, linked from the CV's Portfolio
section.

## How to Run Locally

1. Download or clone this repository.
2. Open the `personal-cv` folder.
3. Double-click `index.html` (or right-click → Open With → your browser).

No build tools, servers, or installations are required — it's a static
HTML/CSS page that runs directly in any modern web browser.

## Deploying with GitHub Pages

1. Push this project to a GitHub repository.
2. On GitHub, go to the repository's **Settings → Pages**.
3. Under **Branch**, choose `main` and the `/ (root)` folder, then save.
4. GitHub will publish the site at `https://<username>.github.io/<repo-name>/`.

Because `index.html` is at the root and the portfolio lives in a
`portfolio/` subfolder with a relative link, both pages work as-is once
published — no extra configuration needed.
